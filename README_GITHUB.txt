GITHUB PAGES - RYCHLY POSTUP

1. Vytvor novy GitHub repository, napriklad: nq-trader-dashboard
2. Nahraj do rootu repository VSETKY subory z tohto balika
3. Na GitHub chod do: Settings > Pages
4. Source nastav na: Deploy from a branch
5. Branch nastav na: main
6. Folder nastav na: /(root)
7. Uloz
8. Pockaj chvilu, GitHub ti vygeneruje link na web

Potom otvor svoju stranku cez ten GitHub Pages link.

Dolezite:
- index.html musi ostat pomenovany presne takto
- icons priecinok musi ostat zachovany
- service worker bude fungovat az na GitHub Pages domene, nie cez lokalne file:// otvorenie
